## 测试执行说明

### 1. 环境准备

```bash
# 检查ADB连接
adb devices

# 安装APK
adb install -r app-debug.apk

# 启动应用
adb shell am start -n ovo.sypw.kmp.examsystem/.MainActivity
```

### 2. 单个用例执行流程

```
1. 截图当前屏幕 (adb shell screencap)
2. 执行测试操作 (tap/input/swipe)
3. 等待页面加载 (1-3秒)
4. 截图结果屏幕
5. 检查UI元素是否存在
6. 记录测试结果到文件
```

### 3. 结果记录格式

每个测试用例的结果保存为独立文件，包含：
- 测试用例编号和描述

- 测试步骤执行情况

- 相关截图路径
