# Round3 测试用例 - 学生考试与教师阅卷完整流程

测试日期：2026-05-16  
测试设备：Android Emulator `emulator-5554`  
客户端包名：`ovo.sypw.kmp.examsystem`  
后端地址：`http://localhost:8080`  
测试账号：`teacher1 / 123456`、`student1 / 123456`

## TC-R3-001 后端与输入环境检查

- 前置条件：后端服务已启动，模拟器已连接。
- 步骤：
  1. 检查 `localhost:8080` 端口连通性。
  2. 检查当前输入法是否为 `com.android.adbkeyboard/.AdbIME`。
  3. 在 Compose `EditText` 中使用 `adb shell input text` 输入英文和数字。
- 期望结果：
  - 后端端口可访问。
  - ADB Keyboard 已安装并可设置为默认输入法。
  - 文本与数字可以写入 Compose 输入框。

## TC-R3-002 教师创建课程、题库、题目与考试

- 前置条件：教师账号登录有效。
- 步骤：
  1. 使用教师身份创建课程 `R3Course0516160039`。
  2. 创建题库 `R3Bank0516160039`。
  3. 创建 5 道题：单选、多选、判断、填空、简答。
  4. 创建考试 `R3Exam0516160039`，关联以上题目。
  5. 将学生 `student1` 加入课程。
- 期望结果：
  - 后端返回课程、题库、题目、考试创建成功。
  - 教师端考试管理中可看到 `R3Exam0516160039`。
  - 学生端可参加考试列表中可看到该考试。

## TC-R3-003 学生参加考试并提交

- 前置条件：学生 `student1` 已登录，考试已发布且进行中。
- 步骤：
  1. 进入学生端考试列表。
  2. 点击 `R3Exam0516160039` 的“开始考试”。
  3. 作答单选、多选、判断题。
  4. 在填空题输入 `Kotlin`。
  5. 在简答题输入 `APIContract`。
  6. 点击交卷并确认。
- 期望结果：
  - 交卷确认弹窗显示 `已答 5 / 5 题`。
  - 提交成功后显示“主观题正在等待教师评分”。
  - 后端提交记录保存 5 道题答案，客观题自动得分为 50。

## TC-R3-004 教师查看提交与人工阅卷

- 前置条件：学生已提交试卷。
- 步骤：
  1. 教师登录。
  2. 进入考试管理，切换到“进行中”。
  3. 点击 `R3Exam0516160039` 的“批阅与记录”。
  4. 点击学生提交记录。
  5. 确认阅卷页显示客观题得分。
  6. 确认填空题和简答题均出现在人工评分列表。
  7. 填空题打 10 分，简答题打 40 分。
  8. 保存批改。
- 期望结果：
  - 提交列表显示 `学生: Alice Student`、`总分: 50`、`待批改`。
  - 阅卷页显示 `客观题得分: 50`。
  - 填空题答案 `Kotlin` 和简答题答案 `APIContract` 均可评分。
  - 保存后提交列表显示 `总分: 100`、`已批改`。

## TC-R3-005 后端评分结果校验

- 步骤：
  1. 查询提交记录 `submissionId=209`。
  2. 校验状态、总分、客观题分、主观题分、各题得分明细。
- 期望结果：
  - `status=2`
  - `totalScore=100`
  - `objectiveScore=50`
  - `subjectiveScore=50`
  - `questionScores` 包含 659=20、660=20、661=10、662=10、663=40。
